# Presentación de 5 minutos

- **`Chispa-Lab-hack4edu-2026.pptx`:** 11 diapositivas con notas del orador y el tiempo de cada una. Se puede abrir en PowerPoint, Keynote o Google Slides.
- **[`guion.md`](guion.md):** el texto para decir en cada diapositiva (≈ 4,6 minutos), útil también como guion del vídeo de 3 minutos (recortando).
- **`img/`:** capturas reales del juego usadas en las diapositivas.
- **`construir-presentacion.js`:** el script que genera el `.pptx` (`pptxgenjs`). Para regenerarlo: `npm install pptxgenjs` y ejecutarlo con las variables `SKILL`, `IMG` y `SALIDA` (rutas de la herramienta, de las imágenes y del archivo de salida).
